# ONVIF informative notes

The original mapping, binding, runtime, Events, media, discovery, integration,
profile and packaging notes in this directory are preserved historical
implementation evidence, predating the **16 September 2026, 0.2-proposed**
consolidation. Their code-path instructions, old physical paths and unresolved
editorial statements are not the current normative authority.

Use the [root specification](../../spec.md), its incorporated machine annexes,
the [current decision register](../editorial/editorial-decisions.json), and
[readable coverage](readable-coverage.md). The [model/API integration guide](model-layering.md)
documents the owned generators, public factory seam and compatibility paths.
The original dated decision snapshot
is retained separately; an earlier unresolved topic or EPR-routing report is
not a newly asserted blocker. Source permissions, process editions and named
editorial approval remain distinct, explicit release gates.

The [standards list](standards-list.json) supplies exact citation URLs and
`localBiblio` entries to the separately owned publication pipeline. Its checks
establish offline reference closure and pinned native document identities, not
external endorsement or live URL availability.
